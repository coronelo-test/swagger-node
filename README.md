Sitio creado con Node y express para probar la integración con swagger.

### Swagger

Es una suite de herramientas de software de código abierto diseñada para crear, estructurar, documentar y probar API web RESTful. Utiliza la especificación OpenAPI para generar documentación interactiva, lo que permite a los desarrolladores y usuarios explorar y consumir servicios sin necesidad de acceder al código fuente.

Para más información: https://swagger.io/docs/specification/v3_0/about/
